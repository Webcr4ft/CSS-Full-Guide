# Color Theory in Design

**Color theory** is the study of:
- How colors work together.
- How colors affect how we feel.
- Which colors look good together.
- How to choose colors for a design or website.

---

## 1. Primary Colors

There are **3 primary colors**:

- Red
- Blue
- Yellow

These are the basic colors used to create other colors.

---

## 2. Secondary Colors

Secondary colors are created by mixing **two primary colors equally**.

- Blue + Yellow = **Green**
- Red + Yellow = **Orange**
- Red + Blue = **Purple**

---

## 3. Tertiary Colors

Tertiary colors are created by mixing a **primary color with a neighboring secondary color**.

Examples:

- Yellow-Green
- Blue-Green
- Blue-Violet
- Red-Orange

---

# Warm and Cool Colors

Colors can also be divided into **warm** and **cool** colors.

## Warm Colors

Examples:

- Red
- Orange
- Yellow

They can make people feel:

- Warm
- Comfortable
- Energetic
- Cozy

## Cool Colors

Examples:

- Blue
- Green
- Purple

They can make people feel:

- Calm
- Peaceful
- Relaxed
- Professional

---

# Color Models

A **color model** is a way of describing and creating colors using specific values.

Common color models include:

- **RGB** = Red, Green, Blue
- **HSV** = Hue, Saturation, Value
- **HSL** = Hue, Saturation, Lightness

You will learn more about these later.

---

# The Color Wheel

A **color wheel** is a circular diagram that shows how colors are related to each other.

Designers use it to:

- Choose colors that work well together.
- Create color palettes.
- Create different color schemes.

---

# Color Schemes

A **color scheme** is a group of colors chosen for a particular design or website.

## 1. Analogous Colors

Analogous colors are **next to each other** on the color wheel.

For example:

**Green → Yellow-Green → Yellow**

They usually create a **smooth, calm, and comfortable** design.

---

## 2. Complementary Colors

Complementary colors are **opposite each other** on the color wheel.

Examples:

- **Green ↔ Magenta**
- **Blue ↔ Yellow**

They create **strong contrast** and make things stand out.

---

# Color Contrast

**Color contrast** means having enough difference between colors so that elements are easy to see.

For example:

**Bad:**  
Light gray text on a white background.

**Good:**  
Black text on a white background.

Color contrast is very important for **web accessibility**, especially for people who have difficulty seeing certain colors.

---

## 3. Triadic Colors

A **triadic color scheme** uses **three colors that are evenly spaced around the color wheel**.

If you connect the three colors, they form a triangle.

Triadic colors usually create a **bright and energetic** design.

---

## 4. Monochromatic Colors

A **monochromatic color scheme** uses **one main color** and creates different versions of that color.

For example:

- Dark blue
- Blue
- Light blue

You can change the **lightness, darkness, or saturation** of the same base color.

This creates a design that feels **unified and harmonious**.

---

# Using Color in Web Development

When designing a website:

1. **Create a color scheme** for your website's branding.
2. **Choose colors based on the feeling** you want your website to give.
3. **Use enough contrast** so everyone can read your website.
4. **Use color to highlight important elements**, such as buttons.
5. **Use colors consistently** throughout your website.
6. Use colors to create **visual hierarchy**, making important elements stand out.

---

# Key Things to Remember

> **Color theory** = Understanding how colors work together and how they affect people.

The main concepts are:

- **Primary → Secondary → Tertiary**
- **Warm ↔ Cool**
- **Color Wheel → Color Schemes**
- **Analogous**
- **Complementary**
- **Triadic**
- **Monochromatic**
- **Good contrast = Better accessibility and readability**
