# DESIGN TERMINOLOGY
==================================================

* Layout
- The arrangement of visual elements (text, images, buttons,
  whitespace, etc.) on a page.

* Alignment
- Positions elements relative to one another to create a clean,
  organized, and consistent design.

* Composition
- The artistic arrangement of visual elements to create a
  harmonious layout.

* Balance
- The distribution of visual weight within a design.
- Can be:
  • Symmetrical
  • Asymmetrical

* Scale
- The size relationship between elements.
- Larger elements usually attract more attention.

* Hierarchy
- Organizes content according to importance.
- Guides the user's eyes toward the most important information.

* Contrast
- Creates visual distinction using:
  • Color
  • Size
  • Shape
  • Texture
  • Brightness
- Also improves readability.

* White Space (Negative Space)
- Empty space surrounding design elements.
- Improves readability and prevents clutter.

* UI (User Interface)
- Everything users can see and interact with:
  • Buttons
  • Menus
  • Text
  • Images
  • Icons
  • Links

* UX (User Experience)
- How users feel while interacting with a product.
- Good UX is:
  • Intuitive
  • Efficient
  • Accessible
  • Enjoyable

* Design Brief
- A document describing:
  • Project goals
  • Requirements
  • Objectives
  • Timeline
- Serves as the roadmap for designers and developers.

* Vector-Based Design
- Digital graphics created using mathematical formulas.
- Can be resized without losing quality.

* Prototyping
- Creating an interactive model of a website or application
  before development.

# UI DESIGN FUNDAMENTALS
==================================================

* Good Contrast
- Maintain readable foreground/background colors.
- WCAG recommendations:
  • 4.5:1 for normal text
  • 3:1 for large text

* Visual Hierarchy
- Arrange content so users naturally notice the most
  important information first.

* Responsive Images
- Images automatically resize for different screen sizes.

* Progressive Enhancement
- Essential content works on every browser.
- Enhanced features are added for capable browsers.

* User-Centered Design
- Focus on user needs, goals, limitations, and preferences.

* User Research
- Studies users to understand:
  • Behaviors
  • Needs
  • Pain points

* Exit Interviews
- Surveys completed by users who leave a product.
- Helps identify reasons for churn.

* User Testing
- Observing users while they interact with an application.

* A/B Testing
- Compare two versions of a feature with different users.
- Determine which performs better.

* User Requirements
- Functional expectations gathered from:
  • Users
  • Stakeholders
  • Industry standards
  • Research

* Progressive Disclosure
- Show only relevant information.
- Reveal advanced options only when needed.
- Reduces cognitive load.

* Deferred (Lazy) Registration
- Users can explore the application before creating an account.
- Registration happens only when necessary.

# DESIGN BEST PRACTICES
==================================================

* Dark Mode
- Use desaturated colors.
- Avoid extremely bright colors.

* Breadcrumbs
- Display navigation path.
- Place near the top of the page.
- Keep readable but unobtrusive.

* Card Components
- Keep cards simple.
- Avoid clutter.
- Use quality media.

* Infinite Scroll
- Loads content automatically as users scroll.
- Best practices:
  • Load More button
  • Back button
  • Loading indicator
  • Accessible footer

* Modal Dialogs
- Pop-up displayed above page content.
- Best practices:
  • Dim background
  • Close button
  • Click outside to close
  • Use HTML <dialog> element when possible

* Progress Indicators
- Show progress through forms or setup.
- Should:
  • Be easy to locate
  • Show percentages or steps
  • Allow users to return to previous steps

* Shopping Cart
- Always visible.
- Use familiar icons:
  • Cart
  • Bag
  • Basket
- Show item count.
- Display total price.
- Provide quantity controls.
- Include remove buttons.
- Use a clear Checkout CTA.

# COMMON DESIGN TOOLS
==================================================

* Figma
- Cloud-based UI/UX design tool.
- Features:
  • Vector design
  • Auto Layout
  • Real-time collaboration
  • Version history
  • Design systems
  • Comments and feedback

* Sketch
- macOS-only design software.
- Popular for:
  • UI design
  • Icons
  • Wireframes
  • Rapid prototyping

* Adobe XD
- UI/UX design and prototyping tool.
- Integrates with:
  • Photoshop
  • Illustrator
  • After Effects

* Canva
- Beginner-friendly design platform.
- Used for:
  • Posters
  • Presentations
  • Social media graphics
  • Videos
  • Website mockups

==================================================
# KEY TAKEAWAYS
==================================================

✔ Organize layouts using alignment, balance, hierarchy,
  contrast, and whitespace.

✔ Design with users in mind by prioritizing accessibility,
  usability, and responsiveness.

✔ Reduce cognitive load through progressive disclosure.

✔ Let users experience value before asking them to register.

✔ Make shopping carts, progress indicators, and navigation
  simple and easy to understand.

✔ Collaborate effectively with designers by understanding
  design briefs and industry-standard design tools.

✔ Strong UI improves appearance.
✔ Strong UX improves usability.
✔ Great products combine both.
